# Understanding File Extensions

## What Are File Extensions?

File extensions indicate the type and format of a file, determining how it should be opened and processed.

## Common File Extensions

### by Category
- **Document Extensions**: .txt, .pdf, .docx, .doc
- **Image Extensions**: .jpg, .png, .gif, .bmp
- **Video Extensions**: .mp4, .avi, .mov, .mkv
- **Audio Extensions**: .mp3, .wav, .flac, .aac
- **Code Extensions**: .py, .js, .java, .cpp
- **Archive Extensions**: .zip, .rar, .7z, .tar
